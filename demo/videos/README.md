# Vídeos de demonstração

Este diretório não contém mídia por padrão. Vídeo doméstico, frames extraídos e
gravações são ignorados pelo Git.

Para ensaiar com um clipe licenciado, salve-o apenas localmente e registre fora
do repositório: origem, licença, consentimento, checksum SHA-256, ausência de PII
e data prevista para exclusão. Nunca provoque desconforto em um animal para
produzir um cenário.

O comando `make demo` usa um padrão visual sintético gerado em memória; nenhum
arquivo de vídeo é necessário.
